# 统一选择框

依据 UI 实作规范第 5.3 节，后台与老师端共 44 处原生 select 已迁移到共享 Select；反馈分类的原生 datalist 也改为可搜索选择框。

## 当前样式

- 普通筛选高 36px，表单高 48px，输入区圆角 8px。
- 下拉面板最小宽 210px，与触发器间隔 8px，圆角 6px，内距 8px。
- 选项高 36px，圆角 4px。选中项用品牌浅底及右侧勾号，悬停与键盘焦点可辨识。
- 超过 8 项显示搜索。反馈分类始终显示搜索。无结果提供文字提示。
- 浮层使用 Portal 避免被表格、弹窗和抽屉滚动区裁剪，并按视口调整位置。

## 使用方式

从 @crazytalk/ui 引入 Select，使用受控 value 和 onValueChange。options 以 JSX option 声明数据，组件不会把这些 option 渲染为原生 select。

Field 自动传递可访问名称、关联 label 和错误状态。禁用、数字取值、空字符串选项保留。单独使用时提供 aria-label。

键盘支持方向键、Home、End、Enter、Esc，以及短列表的文字定位。Tab 与 Shift Tab 关闭下拉并移动到相邻控件，弹窗内保持在表单范围。Esc 关闭下拉时不同时关闭父弹窗。老师端搜索和无结果文案随中英文环境显示。

## 已验证

- 8 项组件行为测试，包括搜索、空结果、禁用、空值、键盘、焦点、弹窗嵌套和英文。
- 16 项后台相关交互回归，包括原有导航建档，以及项目筛选、渠道编号和反馈学员到老师的联动。
- 四个工作区包类型检查通过，UI 检查通过。
- 实际浏览器核对面板最小宽 210、圆角 6、选项高 36、表单控件高 48。
- 反馈抽屉搜索 Molly 后老师自动显示 Destiny；分类搜索“互动”返回对应分类，Esc 后抽屉保留。
- 老师端390px和360px宽无横向溢出，下拉面板保持视口内，月份切换生效，控制台无 error。
