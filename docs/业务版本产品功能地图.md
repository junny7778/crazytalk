# 业务版本产品功能地图

2026-11-18 · 基线为当前工作区 Demo，包含未提交修改。适用于教务后台、老师 H5 和独立家长问卷。配套使用[技术实作与验收方案](业务版本技术实作与验收方案.md)。

同一编号对应同一组页面操作及验收。操作列按用户实际进入页面的顺序阅读。角色、按钮条件、默认值、字段顺序、确认弹窗、取消返回、筛选、空态与中英文文案沿用对应源码。演示身份和样本重置属于环境工具。

2026-11-20 专题规划：ClassIn 按“学员＋老师”建班、成员与排课同步的后续改造，见[修改优化方案](ClassIn排课与班级改造方案_V1.0.md)、[目标功能地图](ClassIn排课与班级功能地图_V1.0.md)及[验收清单](ClassIn排课与班级验收清单_V1.0.md)。三份为待实施规格，不表示下列现有能力已经完成新方案改造。

**01A · 教务工作台**

从侧栏进入授权模块，收起侧栏；Ctrl/Cmd+K 搜索并打开学员速览；从通知进入关联事项。通过头像菜单进入改密和退出。 相同账号重登看到相同业务范围，搜索结果与详情权限一致。

页面依据：[App.tsx](../apps/admin/src/App.tsx)、[AccountPasswordModal.tsx](../apps/admin/src/components/AccountPasswordModal.tsx)

**01B · 角色预览与演示工具**

在 Demo 切换角色查看菜单及按钮，使用演示重置恢复样本；设置返回上一个工作位置。 用不同权限角色比较相同页面；演示重置只影响演示存储。

页面依据：[App.tsx](../apps/admin/src/App.tsx)

## 02 数据看板

**02A · 运营总览 /**

查看课节状态、待确认、待处理反馈、同步异常和课时即将用完；点击事项进入带条件的目标列表。 来源数量和目标列表对同一范围、同一时间一致。

页面依据：[Dashboard.tsx](../apps/admin/src/pages/Dashboard.tsx)

**02B · 项目指标与老师利用率**

选择月份及组织范围，查看目标、实消、应出勤与到课，打开明细并导出；切换老师利用率查看对应时间范围和趋势。 导出与当前筛选一致，汇总数字可追到课节；无可用数据时沿用现有空态。

页面依据：[Dashboard.tsx](../apps/admin/src/pages/Dashboard.tsx)、[OrganizationFilters.tsx](../apps/admin/src/components/OrganizationFilters.tsx)

## 03 学员中心

**03A · 学员列表 /students**

搜索学员 ID 或资料，组合筛选、翻页，点学员打开档案；行内操作沿用其权限和课节条件，取消前先选目标课程。 同名孩子按 ID 分开，取消只作用于所选课节。

页面依据：[Students.tsx](../apps/admin/src/pages/Students.tsx)、[ListPagination.tsx](../apps/admin/src/components/ListPagination.tsx)

**03B · 建档、编辑、导入与导出**

打开资料表单填写并保存；导入时使用现有模板、核对解析结果，选择跳过或更新；导出当前筛选结果。 有 ID 的行更新对应人，留空按新增处理；同批次重复提交不重复建档。

页面依据：[StudentProfileEditor.tsx](../apps/admin/src/components/StudentProfileEditor.tsx)、[StudentImport.tsx](../apps/admin/src/components/StudentImport.tsx)、[DataTransferButton.tsx](../apps/admin/src/components/DataTransferButton.tsx)

**03C · 学员档案 /students/:id · 概述信息**

查看基本资料、画像与历史，编辑资料、绑定 ClassIn、发放问卷；从档案打开统计、待办和对应记录，办理后回到当前学员。 同一个 ClassIn UID 对应一份共享余额。关联先核实账号，再展示已有成员与共享后余额，确认后原子保存关联和余额。仅展示同账号其他学员的链接；历史余额可能重复时先核实，禁止盲目相加。已有共享成员不能单独改绑。历史更正保留原因，待办完成有结果记录。

页面依据：[StudentDetail.tsx](../apps/admin/src/pages/StudentDetail.tsx)、[StudentClassIn.tsx](../apps/admin/src/components/StudentClassIn.tsx)、[StudentHistoryEditor.tsx](../apps/admin/src/components/StudentHistoryEditor.tsx)、[StudentHistoryPanel.tsx](../apps/admin/src/components/StudentHistoryPanel.tsx)、[StudentStatistics.tsx](../apps/admin/src/components/StudentStatistics.tsx)、[StudentTasks.tsx](../apps/admin/src/components/StudentTasks.tsx)、[StudentRecordDrawer.tsx](../apps/admin/src/components/StudentRecordDrawer.tsx)、[StudentActions.tsx](../apps/admin/src/components/StudentActions.tsx)

**03D · 课程与教材进度**

查看课程列表或日历，打开指定课节查看老师、教材、进度、截图及同步信息；从符合条件的课节发起调课。 从历史课节能打开当次进度，从未来课节调课能带入原安排。

页面依据：[StudentCourses.tsx](../apps/admin/src/components/StudentCourses.tsx)、[StudentLessonDrawer.tsx](../apps/admin/src/components/StudentLessonDrawer.tsx)、[CourseSyncLink.tsx](../apps/admin/src/components/CourseSyncLink.tsx)

**03E · 服务跟进**

在学员下登记服务事项、回访、反馈、待办；点击记录打开详情，需处理反馈时进入同一反馈；提醒按现有预览交互展示。 同一事项只出现一次，关联补偿带入正确学员和反馈，放弃编辑沿用现有确认。

页面依据：[StudentService.tsx](../apps/admin/src/components/StudentService.tsx)、[StudentActions.tsx](../apps/admin/src/components/StudentActions.tsx)、[StudentFeedbackDrawer.tsx](../apps/admin/src/components/StudentFeedbackDrawer.tsx)、[StudentTasks.tsx](../apps/admin/src/components/StudentTasks.tsx)

**03F · 停课、复课、结课、退款后停用**

选中学员后选择对应业务动作，填写原因，核对影响的未来课节，勾选已与家长沟通并确认。停课或结课取消未来课并保留剩余课时；复课允许重新排课，已取消课程保持取消。业务版退款按用户2026-11-18确认：清零账号共享余额，所有关联学员停止排课，取消本系统安排的未来未开始ClassIn课节，保留账号及历史；不涉及外部群/其他平台，不执行资金支付退款。Demo保持演示流程。

**03G · 转介绍、回访和关联补偿**

登记转介绍时选介绍人、日期并填写备注。回访时选星级和节点、填写原文，在支持的星级附图；缺星级或内容时显示表单提示。由反馈发起补偿时带入学员和反馈，保存后核对服务跟进和课时明细。

## 04 课时与订单

**04A · 课时与续费 · 购课与账号共享余额**

从学员档案点加课时，选购买类型及 72／144 课时；不再提供“共享已有课时”入口。关联同一个 ClassIn UID 即共享余额。后续购课、补偿和赠送计入同一余额，提交前展示共用成员。原购买记录保留当时成员和购买人；不同学员占用、扣课、返课使用同一套餐，余额不重复累计。未绑定学员可先登记购课，关联时并入账号余额。

页面依据：[StudentCredits.tsx](../apps/admin/src/components/StudentCredits.tsx)、[StudentActions.tsx](../apps/admin/src/components/StudentActions.tsx)

**04B · 期初余额、加课时、手动扣减**

待核余额先录入初始值及原因；账号首次录入余额对全部关联学员生效。历史多份余额或成员不一致时先核对并重新关联，不允许继续分别加减或排课。先核对当前学员的个人或共享余额，再加课时或输入扣减数及原因，保存后核对明细。 扣减前后余额与流水对应，失败无余额变化，共享扣减能看到所属订单。

页面依据：[StudentCredits.tsx](../apps/admin/src/components/StudentCredits.tsx)、[StudentActions.tsx](../apps/admin/src/components/StudentActions.tsx)

## 05 家长问卷

**05A · 发放与填写 /intake/:token**

页面依据：[StudentSurvey.tsx](../apps/admin/src/components/StudentSurvey.tsx)、[StudentDetail.tsx](../apps/admin/src/pages/StudentDetail.tsx)

## 06 老师中心

**06A · 老师列表 /teachers**

按资料和状态筛选、配置可见列，查看老师资料或打开档案；在管理入口保存档案、TM、SO、标签、展示照片和视频。 编辑后列表和详情同步，媒体重新登录仍可查看。

**06B · 老师详情 /teachers/:id**

页面依据：[Teachers.tsx](../apps/admin/src/pages/operations/Teachers.tsx)、[TeacherSchedule.tsx](../apps/admin/src/components/TeacherSchedule.tsx)、[TeacherAttendance.tsx](../apps/admin/src/components/TeacherAttendance.tsx)、[TeacherFeedback.tsx](../apps/admin/src/components/TeacherFeedback.tsx)

## 07 排课

**07A · /schedule · 老师排课与待排课学员**

切换老师排课或待排课学员；按日期、老师看周／日视图，从老师时段或学员进入排课面板。 两条入口带入各自上下文，选中的学员、日期和老师与最终课节对应。

页面依据：[Schedule.tsx](../apps/admin/src/pages/Schedule.tsx)、[StudentSchedulingPanel.tsx](../apps/admin/src/components/scheduling/StudentSchedulingPanel.tsx)

**07B · 固定排课、临时排课与课程计划**

填写排课意向，在固定排课选择老师优先或时间优先，核对匹配及覆盖周次，锁定或释放；临时排课从日历选择可用课次，核对计划和课时后提交。 同时占用同一老师同一时段只能一方成功；成功的课节占用正确权益并释放相应锁。

页面依据：[CoursePlanEditor.tsx](../apps/admin/src/components/scheduling/CoursePlanEditor.tsx)、[FixedPlanCalendar.tsx](../apps/admin/src/components/scheduling/FixedPlanCalendar.tsx)、[FlexStudentCalendar.tsx](../apps/admin/src/components/scheduling/FlexStudentCalendar.tsx)、[StudentSchedulingPanel.tsx](../apps/admin/src/components/scheduling/StudentSchedulingPanel.tsx)、[Schedule.tsx](../apps/admin/src/pages/Schedule.tsx)

**07C · 调课、取消及换师**

从课表或学员记录选中课节，打开对应操作，核对原安排、填写新安排或原因，确认后回到原上下文。 新旧时间、老师、占用及变更历史对应同一课程；有未保存修改时按原交互处理。

页面依据：[Schedule.tsx](../apps/admin/src/pages/Schedule.tsx)、[StudentActions.tsx](../apps/admin/src/components/StudentActions.tsx)、[StudentLessonDrawer.tsx](../apps/admin/src/components/StudentLessonDrawer.tsx)

## 09 反馈

查看原始反馈及历史；按权限登记客服处理、跟进措施和 TM 判定。关联奖惩或补偿时核对来源。 客服完成只改变处理结果；符合规则的 TM 判定进入当期奖惩。

页面依据：[Feedback.tsx](../apps/admin/src/pages/operations/Feedback.tsx)、[FeedbackEditor.tsx](../apps/admin/src/pages/operations/FeedbackEditor.tsx)、[FeedbackContentPreview.tsx](../apps/admin/src/components/FeedbackContentPreview.tsx)、[FeedbackHistory.tsx](../apps/admin/src/components/FeedbackHistory.tsx)

## 10 薪资

**10A · /payroll · 月度薪资与单价**

选择月份和老师，打开工资明细核对课酬来源、计薪课程和扣款，按状态调整、确认；在单价页查看和维护对应项目。 金额能回溯到来源，确认状态及已产生的明细重读一致。

页面依据：[Payroll.tsx](../apps/admin/src/pages/operations/Payroll.tsx)

**10B · 老师与 SO 对账**

选择老师和月份，设置 OP／NP 及对应时薪，核对确认时段或完课、奖惩和调整，确认后查看冻结账单。 分别核对老师与 SO 金额；更改后续费率不会改写已冻结月份。

页面依据：[OfficePayroll.tsx](../apps/admin/src/pages/operations/OfficePayroll.tsx)、[Payroll.tsx](../apps/admin/src/pages/operations/Payroll.tsx)
