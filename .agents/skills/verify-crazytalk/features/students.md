# 学员与课时

教务可以给新学员建档和购课，并在同一份档案里查余额与流水。

## Sub-features

- 建档购课。填写中文名，保存并登记首次购课。
- 查余额和流水。在档案的「课时与续费」查看剩余课时和购课明细，刷新后复核。
- 学员速览和服务跟进按改动手动查看。

## How to get to it (user POV)

从侧栏「学员中心」点「新建学员」，再选「保存并加课时」。查已有记录时点学员姓名进入档案，选「课时与续费」。列表的行内查看入口打开速览，档案的「服务跟进」可查看反馈。

## Driving it with Playwright

先按 [Launch 和 Doctor](../SKILL.md#launch) 启动本地 Demo，确认地址和 Chrome 可用。按以下步骤复跑，也可打开同一地址手动核对页面。

```sh
./scripts/verify-student-credit.mjs
```

1. 从「学员中心」点「新建学员」，填写新姓名的「学生中文名」，再点「保存并加课时」。购课弹窗显示可点击的「确认加 72 课时」。
2. 点击确认。弹窗关闭，新学员档案显示 `72 课时`。
3. 刷新后仍是同一档案，余额仍为 `72 课时`。打开「课时与续费」，该学员的课包余额为 `72 课时`，且只有一条「新购」流水，显示变动 `+72`、变动后余额 `72`。
4. 看终端的 `PASS` 和 `Evidence:` 路径。`result.txt` 记录学员档案地址和刷新后的数值，`ledger.png` 显示对应流水。

## Gotchas

每次运行都使用空白 Chrome 会话和新的学员姓名。手动检查已有学员时，先记下操作前的余额，再比较实际增量。仅保存测试学员的证据，本地 Demo 可能自动读取客服学员表。

导入按当前客服原表模板解析，当前导出含 47 列。已有学员以学员 ID 确认身份。同名或同手机号仍可能是不同学员。反馈侧栏提供只读记录，处理入口打开对应反馈页。


### ClassIn 账号共享余额（2026-11-20）

以同一 UID 为共享单位：在关联账号先核实 UID，查看成员和余额，再确认共享；加课时无独立共享入口。
验证两名学员绑定后显示同一余额；重复绑定不加余额；从任一成员充值、扣课和更正后另一成员同步；预约占用与取消释放不重复计算。
历史导入多份余额不自动求和，成员不一致先核实；禁止单独带走共享余额。正式退费影响同账号全部成员，个人课程与购买流水仍可追溯。
相关测试：studentAccount、sharedOrder、packageLifecycle.acceptance、scheduleCredits、businessEffects，以及 student-forms-v2、shared-credit-detail、schedule-workflows。
