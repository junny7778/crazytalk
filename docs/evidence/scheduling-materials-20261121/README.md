# 排课流程与教材匹配专项验收（2026-11-21）

本次为本地开发实作，未部署。复用运行中的 5173 Demo 服务；Demo 业务日期固定为 2026-10-31。浏览器测试使用独立临时浏览器上下文，不改用户已有浏览器数据。

## 完成内容

- 老师详情的教学信息增加“可授教材”字段；学员“课程与教材进度”的原课程安排区域增加“学习教材”字段。均以标签展示、多选登记，沿用“编辑资料”，未新增独立模块或入口。
- 保存教材时保留全部原资料字段、当前教材和学习进度。旧学员单教材仅按教材目录精确识别；老师未登记教材时不自动推定可授课。
- 一键排课先确认本次教材和意向，再选并排的“老师优先／时间优先”。推荐老师以两列卡片显示资料、教材匹配、偏好原因、本人可排节数、整个方案覆盖和缺口，直接进入方案日历。
- 老师优先尽量由同一老师承担；时间优先提供明确的多老师组合。预览中可以逐节调整教材、老师和时间，缺口在当前页面提示，不增加异常汇总页面。
- 自定义排课统一使用日历，支持多选、按周重复、拖动、预览及确认。按老师使用学员卡片与共同教材，也支持先选时段再选学员；原完整日历多选的全部时段会带入。
- 复用现有日历样式、周／日视图、课表筛选、课程状态和详情。日视图按天翻页。查看状态与草稿编辑分开。
- 学员登记教材、老师可授教材、每节课程教材在提交处强制校验；手动确认不能绕过。保留余额、占用、冲突、ClassIn 账号与老师确认校验。
- 草稿可恢复；明确放弃或成功提交后清除对应草稿；修改学员、教材、时长或重复周期时保护未提交内容。
