# ClassIn 真实联调待测清单

2026-11-18 用户明确要求：暂不测试涉及真实老师、学员账号的操作。以下全部是待评估清单，不代表授权执行。没有发送真实注册、建课、改课、换师或取消请求。

## 测试前需提供/确认的信息

- 测试机构使用哪一套服务端配置（无需在文档或聊天中公开SID/密钥）。
- 允许使用的老师账号与学员账号：手机号/邮箱或已核实UID，是否已加入测试机构及对应身份。
- 是否测试“新注册”；如测试注册流程，需要账号持有人同意，初始密码仅新账号生效，由安全配置/现场输入提供，不记录于验收文档。
- 允许测试的日期、开始/结束时间、时区，课程名称标识；改课测试应安排在开课20分钟之前，不能选即将进行的真实课。
- 谁负责查看ClassIn后台/客户端，与本系统记录核对；是否允许该测试账号出现测试班级和课节。
- 公网HTTPS回调地址、后台订阅事件和可达状态。未准备好时先做不依赖回调的测试。

最小常规联调可先用1位老师+1个学员账号。换师需要第2位老师；共享退款使用同一学员账号下2个本系统测试学员；若验独立账号不受影响，再加第2个学员账号。由用户选择执行范围，不要求一次提供所有对象。
