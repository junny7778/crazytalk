# 排班

## Sub-features

周日视图、待排课、找老师、固定临时课、冲突、空档图。

## How to get to it (user POV)

排班管理 → 待排课 → Lucy → 找老师 → 给 Lucy 排固定课。

## Driving it with cua_repl

默认意向为下周一与周三 19:00。选择 Carol，确认 8 周 16 节。检查 Lucy 从待排课面板移除，日历出现两块课程，并在其档案看到接下来的课。再次在同一时段排课，必须被冲突预检阻止。切日视图，点老师列头返回其周视图。

## Gotchas

Lucy 已排课时先恢复演示数据。过去日期不可排。找老师检查未来 4 周，排课确认检查所有已选周。空档图不得包含其他学员姓名。
