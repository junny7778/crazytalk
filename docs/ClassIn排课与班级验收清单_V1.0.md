## 1. 验收方式

每次修改只运行对应功能及实际受影响调用方的用例；下表是完整验收目录，不代表每次修改都跑 52 项。每行是业务场景，可以合并到已有测试文件，不必为每行新建脚本。用例只覆盖核心正常路径及本方案明确涉及的异常。

|层级|证明什么|不能替代什么|
|---|---|---|
|L1 领域/接口契约单测|分班规则、参数、返回码、状态、扣返与签名|数据库持久化、真实机构可见性|
|L2 隔离数据库＋API＋模拟 ClassIn|权限、事务、唯一约束、任务执行、故障恢复、重读|外部平台是否真支持或已经执行|
|L3 页面交互|入口、预览、缺项提示、刷新、深链与各角色可见结果|仅页面 mock 不证明真实业务 API|
|L4 指定真实测试对象联调|ClassIn 实际班级、成员、课堂、回调与客户端可进入|未测试的其他账号、平台能力和历史数据|

不启动生产构建、不部署。API 测试使用隔离 schema；界面可复用现有本地服务。真实 ClassIn 写入只在测试账号、课节时间、操作范围明确后执行，本清单本身不是执行授权。
