# 老师离职专项验证（2026-11-20）

## 已实现

- 离职弹窗按实际受影响学员、未来未开始课节展示淡黄色或淡红色提示；人数去重，仅绑定未预约也计入。已停课等学员仍有未来预约时不会显示无影响提示。
- 保留离职原因，提交期间统一 loading，关闭和重复提交受限制，不展示逐节步骤。
- 解除当前老师绑定，清理该老师的临时固定占位，取消未来未开始预约；排课版本递增使旧计划失效。当前系统没有独立的后台固定课自动生成规则，固定课由预约课节表示；学员上课意向保留。
- 多老师场景保留其他老师预约和占位；仍需继续学习的学员获得重新排课待办。无其他安排的学员转待排课，多老师学员保留在读并进入待排课列表。停课、结课、退费状态保持不变。
- 待办记录待补排课节的时长和替代课程 ID。逐节匹配同等时长的补排，全部补齐且同步确认后自动完成；仅补一节、同步失败均不会提前完成。
- 取消未确认时保留预约额度与占位，受影响学员沿用原课程取消确认前的重新排课限制；其他学员不受阻塞。
- ClassIn 失败提示明确老师已离职、部分课节尚未取消；重复离职不会重复派单或再次创建取消任务。
- 学员详情在重新排课后展示实际老师，不被“待重新排课”的历史换师记录覆盖。
