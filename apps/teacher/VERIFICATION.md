# 老师端 Demo 专项验证

本地运行：在工程根目录执行 `pnpm dev:teacher`，打开 http://127.0.0.1:5174/。后台也可在同一源的 `/teacher` 路径打开老师端。两个端口的浏览器存储分别隔离，同源路径可共享业务数据。

## 已验证

- `pnpm --filter @crazytalk/teacher typecheck` 通过。
- 真实页面打开首页，能够看到本人课程、待结课、通知、下一节课。
- 结课空表单提交显示英文必填提示。
- 填写结束页码 48、评分 4、25 个英文词以上评语后提交成功，待结课计数从 8 变为 7。
- 在账号页切换为中文，导航与页面文字即时变化。
- 390×844 和 360×780 页面宽度均等于视口宽度，无水平溢出。
- 首页没有显示学员或家长手机号。

验收截图保存在工程 `docs/evidence/teacher-home-zh-390.png` 和 `teacher-home-zh-360.png`。

## Demo 边界

- 固定使用 Carol 的演示身份。账号页不接正式认证服务。
- 可上课时间为一组每周日期和统一起止时间，尚不支持每天不同的多个时段。
- 影响已排课程的时间变更先提交教务审核，不直接覆盖课表。
- 培训提供可阅读的音频指南及一道测验，完成结果保存在本机。
- 薪资只显示已确认和已发放月份的金额，金额及单价用于演示。
- 只显示已完成责任判定的反馈，不显示学员课时余额、家长联系方式及后台内部评价。
- 不将本次专项检查描述为全量回归或真实 ClassIn 联调。
