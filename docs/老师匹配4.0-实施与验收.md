# 老师匹配 4.0：实施方案与功能地图

基准：2026-11-19 对话确认、《老师标签体系&匹配规则.xlsx》的「学员&老师匹配 优化4.0」。本轮实施不部署。

## 已确认边界
- 现有问卷题目、年龄分组、L1–L3、提交回写、分享方式保持不变；绝对雷区不处理。
- 同类名称统一成标准标签，按稳定 ID 关联，不重复计分。基础、经验等明确不同等级保留。
- 匹配仅依据年龄与基础、性格、兴趣；不加入 P0–P4、必须 A 类、新家长偏好评分。
- 一级标签匹配优先，再比较二级；爱迟到自动推荐降序并提醒，不发明配额。
- 老师优先按适配、时间优先按本人覆盖；无重合时间仍展示但不优先。
- 单老师完整覆盖优先，多老师方案明确分工并由教务确认。
- 暂停接新仅限制无该老师授课关系的学员。自动推荐按风险规则处理；手动不新增标签拦截，原有排课校验保留。
- 卡片固定模板生成，老师中文、学员英文；预览可编辑、复制、图片导出，不自动发送，不污染档案。

## 实际实现入口

- 标签定义、别名及初始化：`packages/shared/src/teacherTags.ts`；基础资料维护复用 `catalog.save`，老师标签存储标准 ID。
- 标签库界面：`Settings.tsx` 的基础资料 → 老师标签；老师录入/展示由 `TeacherTagPicker.tsx`、`Teachers.tsx` 实现。
- 匹配关系、风险和一级/二级比较：`packages/shared/src/teacherMatch.ts`。年龄与基础、性格、兴趣按 4.0 映射。
- 自动固定方案：`fixedPlans.ts`；界面 `StudentSchedulingPanel.tsx`。单老师完整覆盖优先、本人覆盖与总覆盖区分、无时间候选靠后。
- 方案来源：`FixedPlanCalendar.tsx`、`CoursePlanEditor.tsx` 比较老师/日期/时间等实质内容；未改方案提交 recommended，手动调整提交 manual。只修改确认勾选不改变来源。
- 后端复核：`domain.ts` 的 lesson.schedule 对 recommended 再检查标签风险；manual 保留原有排课检查。
- 灵活排课：`FlexStudentCalendar.tsx` 对可用老师按适配排序并显示提醒，手动不因标签禁配。
- 学员匹配画像：`StudentSurvey.tsx` 展示规则来源和缺项。未修改 studentSurvey.ts 问卷定义和问卷提交处理。
- 卡片：`profileCards.ts`、`ProfileCard.tsx`；老师/学员详情入口，公共标签白名单、英文模板、预览调整、复制和 PNG。

## 老师资料信息结构与交互优化（2026-11-19）

- 新建/编辑按基本信息、教学信息、对外介绍、排课信息、培训与内部记录排序；短字段双列，长文本独占一行。教学经验与教师寄语与教学特色分别保存；备注明确为内部备注。
- 详情按对应类别展示，保留课表、学员、考勤、反馈、培训等操作页签；开课日期和排课限制放到可上课时间页签。教学经验及教师寄语完整回显。
- 标签按分类紧凑排列，只展示名称、选择状态和已选数量；支持搜索及移除，不在选择器展示释义、匹配建议或嵌套滚动列表。

## 老师简介卡视觉更新与教育背景

- 教育背景为选填多行文本，位于证书之后、教学经验之前；详情和简介卡复用同一字段。中英文不拆字段。
- 老师卡使用暖橙金色山景、圆形头像、白色圆角卡片、底部居中原品牌 Logo。取消复制文本和标签展示，未填写项不输出；未提供外教类型，不推断国籍。
- 600px 基准：姓名 24/600，字段标题和寄语标题 16/500，正文（含教育背景）14/400。1200px PNG 等比例高清导出；预览直接展示相同图片，随内容自动增高，中英文换行。仅本次卡片可调整内容，不修改档案。
- 26 项相关测试通过，工作区类型检查通过。浏览器验证教育背景保存/刷新、无复制按钮、1200px PNG 实际下载、临时修改与档案隔离。证据 `docs/evidence/teacher-card/teacher-card.png`，脚本 `scripts/verify-teacher-card.mjs`。本次未部署、未执行全量回归。
