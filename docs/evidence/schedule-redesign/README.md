# 排课管理交互优化验收

本次仅调整管理端排课页面、展示计算与交互流程。未修改 packages/shared 业务规则或 apps/api / ClassIn 接口。

## 已完成

- 默认按学员排课，当前授权范围内全部学员可查，按排课情况排序，支持姓名/ID搜索、状态筛选。
- 左栏只保留头像、姓名、ID。使用全局导航同款选中态。
- 右栏初始展示课时余额、已有占用、可用课时、计划进度、未来及历史课程；共享余额注明统计范围。
- 老师初始展示本周课节、已排时长和常规可授课时间。实际剩余空档查看完整课表，不将简单相减伪装成扣除请假等因素后的可用时长。
- 固定推荐默认展示首选方案，其他方案、匹配信息和锁课偏好按需展开。
- 自定义及灵活课表按“设置/选时间 → 预览确认”提交；返回保留内容；固定重复安排返回调整后不重复展开周期。
- 保留已有固定/灵活排课意向及原有匹配、余额、权限、老师确认和冲突校验。
- 已有课节通过详情调整时间，展示原、新时间；换师仍使用原有业务入口。
- 离开编辑、切换人员或Tab保护未提交草稿，提交过程中阻止退出及重复提交。
- 排课成功回到当前对象概况，显示保存结果与原有ClassIn同步状态。

- 顶部只保留对象名称与步骤，当前步骤随设置/预览变化；移除卡片重复标题及顶部重复返回按钮。
