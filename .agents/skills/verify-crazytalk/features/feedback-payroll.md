# 半月工资单与反馈奖扣

## Sub-features

按课计薪的 NP 老师由考勤和教务核定结果生成课酬。按固定课表计薪的 OP 老师由每个完整半小时生成保障底薪。工资单分别列老师与 SO 的底薪、奖扣、调整和待核事项。确认工资单会冻结双方结果，实际付款后由财务手动标记已发放。

## How to get to it (user POV)

在「上课记录」查看课程是否已完成。进入「薪资」，用「结算周期」选择起止日期。老师明细行可以「查看工资单」。在「SO 汇总」点击「查看老师明细」，可查看该 SO 在相同周期和筛选条件下的老师。课程待核时，从明细打开对应上课记录核定结果。好差评在「反馈」完成 TM 判定，工资单按判定日期归期。

## Driving it with the payroll API test

从 crazytalk-ops 根目录运行。复用本地开发 PostgreSQL、apps/api/.env 及已安装的项目依赖。先用 `lsof -nP -iTCP:3191 -sTCP:LISTEN` 确认端口空闲。验收程序自行创建随机数据库 schema、迁移、启动隔离 API 并登录。此前已有服务占用 3191 时，先查明进程，不要对该服务运行验收。

```sh
mkdir -p .playwright/verify-crazytalk
pnpm --filter @crazytalk/api exec tsx src/business.integration.ts --payroll > .playwright/verify-crazytalk/payroll-api.log 2>&1
cat .playwright/verify-crazytalk/payroll-api.log
```

检查验收命令退出码为 0，日志出现 PASS，并逐项核对下表。验收程序会检查断言；若失败，日志给出具体步骤和实际结果。

| 动作 | 预期可观察结果 |
|---|---|
| 通过业务 API 排一节 25 分钟的普通 NP 课 | 预计课时为 1，尚无已确认课时 |
| 模拟 ClassIn 已结束，再发送师生正常考勤，重发同一考勤 | 仅结束时课程待确认；收到正常考勤后由服务定时任务自动完课。余额从 5 到 4，只有一笔扣课流水 |

| 确认，修改老师单价，再标记已发放 | 重读的工资单明细与确认前完全一致，状态为「已发放」 |

## Gotchas

为一次运行就能覆盖半月关账，脚本先通过真实排课接口预约，再仅在隔离数据库把这节课的日期调到已结束的半月并建立测试用 ClassIn 课节映射。考勤经本地签名回调 HTTP 入口进入，自动扣课由真实服务的 30 秒定时任务执行。测试服务只允许本机网络访问。退出时清理本次服务、测试 schema 和上传目录，日志保留在上面的路径。

## 2026-11-25 本地实测

隔离 PostgreSQL API 实测一次排课，重复发送两次模拟考勤后只扣了一次课时。自动完课以后、财务确认以前改价，原课程仍按老师 ₱180、SO ₱60 结算。

Chrome 三项流程全部通过。1280 × 720 的老师列表与 SO 汇总可核对并导出，在 390 × 844 的工资单抽屉中可查看应结和实际发放状态。无预约 OP 老师办理离职后仍能在当期看到固定底薪。表单日期框距视口顶部 540 像素时日历向上，145 像素时向下，两处均可选日。

领域专项通过 36 项薪资与核定测试、8 项离职测试。页面另通过 2 项实际取消和核薪测试、6 项老师离职相关测试。本次使用本地模拟 ClassIn 回调。

最终增量验收通过 7 项。固定时段 19:00–20:00 在 19:59:59 保留老师 ₱360、SO ₱120，并提示待核，20:00 可以确认。3 分钟迟到按每分钟 ₱2 计 ₱6，10 分钟达到单节上限 ₱18，明细显示计算依据。特殊时长的扣课与免扣，以及核定后 NP 转 OP 的原课计薪均通过。权限组已登记「导出薪资明细」，只有查看权限的账号看不到按钮，有导出权限时可以导出全部 26 条筛选结果。
