## 可重复入口和证据

- `pnpm test --maxWorkers=4`：本轮83文件604项通过（随后新增businessClient边界3项专项通过）。
- `pnpm test:business:api`：真实隔离schema组合验收，含 modules.integration、workflow、intake、scope、附件；本轮通过。
- `pnpm --filter @crazytalk/api exec tsx src/integrations/verify-worker.ts`：真实隔离DB/mock外部API，包含课程ID恢复、老师UID变更、回调扣返和退款取消汇总；本轮通过。
- `node tests/e2e/run-isolated.mjs`：隔离浏览器写流程，自动创建并清理schema，禁止外部网络。最新具体结果看模块浏览器验收补充.md。
- `pnpm typecheck`、`pnpm check:ui`：本轮通过；没有执行生产构建或部署。
- 历史 `tests/e2e/frontend.business.spec.ts` 会使用本地业务环境，不应直接当成隔离测试重跑；新写流程使用run-isolated。

证据保存在 `docs/evidence/business-2026-11-18/`。接口专项分组见模块API验收补充.md；浏览器范围、截图和未测项见模块浏览器验收补充.md。
