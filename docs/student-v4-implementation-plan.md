# 学员事件驱动优化：实施与验收范围

依据：本次对话用户已确认的整体修改方案。仅本地前端Demo，不部署、不真实对接、不清空现有资料。列表保留现有列及下拉筛选，无快捷视图，导入导出文字按钮保留。学员ID继续8位及完整关联。

## 新建与编辑

普通新建：姓名必填，群名/手机/年龄/性别/性格/外教经验/偏好/渠道/负责教务，以及可选在职老师、初始教材和进度。删除原序号/订单状态/买单日期/总课时/是否续课/上课时间频次首课/月度记录/历史次数/换师历史。正常状态、待安排课程、已知0余额；初选老师不等于排课。三个保存入口可用。

编辑：基本资料/归属/偏好可改，仅提交修改字段并检查相同字段冲突；已有关联老师只走换师。无课后报告可以更正初始教材进度，有报告后更正对应报告；旧表单保存不能覆盖新进度。

历史：独立补录/更正入口，保留旧原表全部资料及月度/次数/换师数据；原因必填，留修改前后及经办人时间。起算范围明确且不重叠才能合并历史与系统计数；未知不冒充0，不人为构造历史逐节课程。

## 统计与查看

月应上课：课程日期所在月份，所有非取消已排课节数，完成仍计；跨月调课重算两个期间。实际：已完成且实际出席，扣课缺席不算实上。投诉：每条差评一次，处理/跟进不增，改好评重算。补偿：每笔补偿一次，3课时也是1次，赠送/充值不计。被缺席：老师缺席且课程结果已确认结束，每课1次；提前取消/调课不计。每个数字可在档案内查来源。

当前教材进度按最新课程上课时间的报告派生，补旧课不倒退；临时课不改主要老师。课程时间/频次从真实固定安排显示，无固定安排显示临时或未安排。首次实际课从实际完成出席课程计算，历史日期来源保留。

五详情页签保留。新建没有后续课显示待安排；未知历史不显示0。课时、续费、补偿分开查看；余额由初始值+有效流水维护。介绍人仍为系统已有学员，待办处理总结非必填。

## 状态

正常可办理教学和购课；停课/结课/退款完整保留历史和余额；复课之前不可排课、调课、换师。停课/结课/退款预览未开始课程并取消；复课不复活取消课，不因补偿/充值自动复课。退款保留停用进展和遗留待办，不真实退款。

## 验收

独立Agent不参与实现，功能与UX一起验收，REJECT后修复并复测。范围包含：新建0余额和删字段、资料编辑冲突、跨月/取消统计、出勤口径、差评/补偿/老师缺席的计数及下钻、历史未知/重叠防重、更正审计、最新报告、临时老师、各服务状态、ID及已有数据保留。专项测试和真实UI路径，不自动全量回归或构建。不得重置用户演示数据。
